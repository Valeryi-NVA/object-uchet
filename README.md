# ОбъектУчёт

Full-stack приложение для учёта объектов, выездов, цеховых смен, расходов и зарплаты.

В текущей бизнес-логике менеджер оплачивается по дневной ставке, а отдельные
доплаты фиксируются на конкретном выезде. Расходы содержат только категорию и
свободное описание ответственного, без денежной суммы. Роль «Начальник цеха»
не имеет ставки и может отмечать цеховые объекты выполненными. Архивы выездов и
выполненных цеховых объектов доступны через фильтры соответствующих разделов.

Новая модель доступа использует несколько ролей пользователя, отдельный тип
сотрудника (монтажник или сотрудник цеха), статус рабочего и электронный табель.
Персональный QR сотрудника открывает режим отметки, а серверная сессия связывает
отметку с авторизованным пользователем. Статусы и изменения данных записываются
в журнал аудита.

## Локальный запуск

1. Создайте PostgreSQL-базу и скопируйте `.env.example` в `.env`.
2. Укажите `DATABASE_URL`.
3. Выполните:

```powershell
npm.cmd install
npm.cmd start
```

Приложение будет доступно по адресу `http://localhost:10000`.

## Публикация на Render

Файл `render.yaml` описывает web service и PostgreSQL database. Подключите Git-репозиторий в Render и создайте Blueprint из корня проекта. Render установит зависимости командой `npm ci` и запустит `npm start`.

## Архитектура

- `server.js` — Express API, серверные сессии, валидация, роли и PostgreSQL.
- `public/index.html` — пользовательский интерфейс.
- `schema.sql` — SQL-схема для ручной инициализации базы.
- `index2.html` — исходный файл до миграции, сохранён для сравнения и отката.

При первом чтении старого состояния сервер автоматически обнуляет прежнюю
месячную ставку менеджера и помечает миграцию в `meta.managerRateVersion`.

Авторизация использует HttpOnly-cookie и `scrypt`. Пароли и состояние приложения
больше не хранятся в `localStorage`.
